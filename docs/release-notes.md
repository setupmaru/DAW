Pro Tools처럼 여러 오디오 트랙을 녹음하고, 타임라인에서 편집하고, 믹서에서 VST3 플러그인을 걸어 섞은 뒤 WAV로 내보내는 DAW입니다. (v2.0.0부터 방송용 마이크 이펙트 앱에서 멀티트랙 DAW로 바뀌었습니다.)

## 설치와 실행 (Windows 10/11, 64비트)

1. 아래 **`DAW-Setup-v…exe`**(설치 파일)를 받아 실행하고, 안내에 따라 설치합니다.
   - 코드 서명이 없어서 Windows가 "PC 보호" 경고를 띄울 수 있습니다. 그럴 때는 [추가 정보] → [실행]을 누르세요.
   - 시작 메뉴에 `DAW`가 생기고, 원하면 바탕 화면 아이콘도 만들 수 있습니다. 지울 때는 Windows의 [설정] → [앱]에서 제거합니다(설정과 세션은 남습니다).
   - 설치 없이 쓰려면 `DAW-v…-windows-x64.zip`을 받아 압축을 풀고 `DAW.exe`를 실행하세요.
2. **녹음할 때는 헤드폰을 쓰세요.** 녹음 준비(R)한 트랙은 입력 소리를 바로 들려줍니다.

## 들어 있는 기능

- **트랙과 트랜스포트:** 오디오 트랙 최대 64개, 재생/정지(Space), 녹음(Ctrl+Space), 처음으로(Enter), 선택 구간 반복(Ctrl+L), 메트로놈, 템포
- **녹음:** 녹음 준비(R)한 트랙마다 24비트 WAV, 장치 지연 자동 보정, 정지 중·녹음 중 입력 모니터링
- **입력 모니터 I (2.0.1):** 트랙의 [I]를 켜면 재생 중에도 클립 대신 입력 소리를 들려줍니다(Pro Tools의 TrackInput)
- **편집 창:** 파형, 마디|박·분:초 눈금자, 트림/선택/잡기 도구(F6/F7/F8), 슬립/그리드 모드(F2/F4), 클립 이동·복사·트림·페이드·분할·복제·삭제, 실행 취소
- **믹스 창(Ctrl+=):** 트랙마다 VST3 인서트, 입력, 팬, 페이더, 미터, 마스터 채널. 플러그인 지연 보정
- **세션:** 세션 폴더(`.dawsession` + `Audio Files`)로 저장/열기, 오디오 가져오기(끌어다 놓기 가능)
- **믹스다운 내보내기(Ctrl+Alt+B):** 전체 또는 선택 구간을 WAV로 오프라인 렌더
- **장치:** ASIO 포함, 고른 장치를 다음 실행 때도 엽니다

## 알려진 제한

- 실제 오디오 장치와 VST3 플러그인으로 듣는 검증은 아직 충분하지 않습니다. 문제가 있으면 [Issues](https://github.com/setupmaru/DAW/issues)로 알려 주세요.
- 클립 오디오를 메모리에 올려 재생합니다. 아주 긴 세션은 메모리를 많이 씁니다.
- MIDI, 오토메이션, 센드/버스는 아직 없습니다. 트랙 삭제와 믹서 조작은 실행 취소되지 않습니다.
- 대부분의 ASIO 드라이버는 한 번에 한 프로그램만 쓸 수 있습니다.
